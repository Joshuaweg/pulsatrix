Detailed Description

While alive, merges bn's affine map into conv's weights and makes bn an exact identity; on destruction, restores both bit for bit.

Note
With s_c = gamma_c / sqrt(running_var_c + eps), the merged convolution has kernel w'[c] = s_c * w[c] and bias b'[c] = s_c * (b[c] - running_mean_c) + beta_c. The pair computes the same function before and during the fold (up to float rounding), but LRP now distributes relevance through one affine layer with the convolution's own rule, instead of passing it unchanged through BatchNorm's identity rule.
Use it as a scope around explaining: { BatchNormFold fold(conv, bn); auto r = lrp.explain(...); }. Don't train while a fold is active: gradients would update the merged weights, and the restore would overwrite those updates.
