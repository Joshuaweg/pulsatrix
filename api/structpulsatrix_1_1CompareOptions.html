double pulsatrix::CompareOptions::metric_tolerance = 1e-5

A metric regresses when the candidate exceeds the baseline by more than this absolute amount (metrics such as conservation error are near zero, so a fraction of the baseline would be meaningless).

◆ significance

double pulsatrix::CompareOptions::significance = 0.05

With at least three rounds on each side, a time also needs the candidate's rounds to be slower than the baseline's with this one-sided Mann-Whitney p-value. Separate processes of the same build can differ by 20% on sub-millisecond work, so medians alone raise false alarms; a real slowdown makes every round slower.
