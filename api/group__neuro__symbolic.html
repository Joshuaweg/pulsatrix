Detailed Description

A differentiable fuzzy-logic core (Logic Tensor Networks-shaped t-norm/t-conorm operators, a p-mean quantifier aggregator, and a satisfaction loss trainable via ordinary gradient descent) plus a from-scratch Datalog engine (bottom-up fixpoint evaluation, a real-valued/weighted generalization, and a hand-derived LRP rule) – and a bridge wiring a real neural predicate's output in as a Datalog base fact's weight, so relevance traces from a symbolic derivation back into the network.
