std::vector<double> pulsatrix::EncoderLMConfig::rope_inverse_frequencies

RoPE frequencies to use instead of rope_theta's, one per pair. LoadEncoderLM fills them from the checkpoint's inv_freq buffer: ESM-2's are stored rounded to fp16 (0.316162 rather than 0.316228), the model was trained with those, and transformers uses them, so recomputing them exactly shifts attention by about 2e-4.
