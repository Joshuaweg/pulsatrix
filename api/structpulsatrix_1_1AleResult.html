Detailed Description

First-order accumulated local effects (Apley and Zhu 2020) of one feature.

The feature's range is cut at quantiles into bins holding about equal numbers of instances. Within each bin, every instance in it is moved to the bin's lower and upper edge and the change in the output is averaged; the averages are summed from the left and centered so their count-weighted mean is zero. Because each instance only moves within its own bin, ALE never reads the model at combinations of feature values the data doesn't contain, which is where PDP misleads when features are correlated.
