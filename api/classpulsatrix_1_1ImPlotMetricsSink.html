Detailed Description

A concrete MetricsSink (metrics_sink.hpp's own doc comment names this the expected extension point: "Concrete writers... implement this") that buffers every logged scalar into a per-tag time series, and keeps the latest histogram snapshot per tag, for live rendering by a training dashboard. Zero core changes needed – MetricsSink* is already threaded through every training loop in this codebase (XorNetwork::train_step, MnistConvNet::train_step).

Note
This header has no ImGui/ImPlot include – log_scalar()/log_histogram() and the accessors below are implemented in src/implot_metrics_sink.cpp (unconditional, part of pulsatrix_core) and are unit-tested directly. Only Draw() (implemented in src/viz/implot_metrics_sink_draw.cpp, part of the gated pulsatrix_viz target) calls into ImPlot, and is deliberately not unit-tested – see plans/okay-we-have-now-buzzing-moth.md Testing Strategy.
