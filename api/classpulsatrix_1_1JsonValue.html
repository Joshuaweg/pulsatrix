Detailed Description

One JSON value: null, a boolean, a number, a string, an array or an object.

Note
Objects keep their keys in insertion order, and the writer emits them in that order, so the same value always serializes to the same bytes. A number keeps the exact text it was parsed from, so as_float() and as_double() each round the decimal text once, directly to their own type, instead of going through double first.
