Detailed Description

Minimal RFC-4180-ish CSV parser: comma-delimited, double-quote-quoted fields, "" as an escaped quote,
or \r
line endings. Whole file loaded into memory at once – no streaming/chunked reading in this phase, matching MnistIdxLoader's own whole-file-at-once precedent.

Note
Chosen over fetching Arrow C++ (campaign_exai_dl_library_data_pipeline Decision Point 1): Arrow's columnar/zero-copy value proposition doesn't apply to this row-oriented, float32-only, small-scale use case, and would break this project's minimal-FetchContent discipline (GoogleTest + optional pybind11 only, today).
