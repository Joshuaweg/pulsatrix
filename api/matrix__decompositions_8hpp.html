Detailed Description

Small dense decompositions on the host: symmetric eigensolver, power iteration, QR and SVD (roadmap FND-4).

Note
For the matrices interpretability works with – covariances of activations, weight matrices, Gram matrices – up to a few hundred rows and columns. Inputs are CPU tensors; arithmetic is in double; results are float tensors on the input's backend.
Eigenvector and singular-vector signs are arbitrary mathematically, so every result here is made canonical: in each vector, the largest-magnitude entry (the first, on a tie) is positive. Values come in descending order, ties kept in a fixed order. The same input therefore always gives the same output, which makes vectors comparable across runs and models (PCA directions, intruder-dimension checks).
