Detailed Description

A small JSON Schema validator for tool inputs.

It supports only the keywords that mean the same in JSON Schema draft-7 and 2020-12, so one schema works with the Anthropic API, OpenAI-compatible servers and MCP clients, whichever draft they assume:

  • type (a name or an array of names), enum, const
  • objects: properties, required, additionalProperties, minProperties, maxProperties
  • arrays: items (one schema for every element), minItems, maxItems, uniqueItems
  • strings: minLength, maxLength (in Unicode code points)
  • numbers: minimum, maximum, exclusiveMinimum, exclusiveMaximum (numbers), multipleOf
  • combining: allOf, anyOf, oneOf, not
  • annotations, which are accepted and not checked: title, description, default, examples, format, $comment, and $schema naming draft-7 or 2020-12

Any other keyword is refused when the schema is checked, rather than silently not enforced. That includes $ref, $defs/definitions and dependencies, whose spelling or meaning changed between the drafts, items as an array (2020-12's prefixItems), and pattern, since a regular expression engine that is safe on hostile input is more than this needs.
