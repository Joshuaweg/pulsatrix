Detailed Description

A set of points in R^dimension, built from activation batches.

Add batches with add(); each is a tensor with the batch on its first axis. The first batch fixes the dimension, and every later one must give points of the same dimension. Batches may differ in their number of positions, so texts of different lengths can be added one by one.

Points are stored on the host as float32, as the activations were; ToTensor() places them on a backend for the distance computation.

PointCloud cloud({PointPooling::PerPosition});
model->set_hidden_state_hook([&](int64_t position, const Tensor& h) {
if (position == 6) cloud.add(h); // (1, tokens, width): one point per token
return h;
});
for (const auto& text : corpus) (void)model->forward(Encode(text));
// cloud.size() points of cloud.dimension() = width; cloud.origins()[i] says which text and token.
