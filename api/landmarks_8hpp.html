Detailed Description

Farthest-point landmarks: a subset of a large point cloud that covers it, with a certified bound on what persistent homology loses by using the subset.

Persistent homology above H0 can't run on 100,000 activations. Farthest-point (maxmin) sampling picks landmarks greedily, each the point farthest from those already picked, so they spread over the whole cloud. Every point is then within the covering radius e of a landmark; the landmarks are within Hausdorff, hence Gromov-Hausdorff, distance e of the cloud; and Rips stability gives d_B(Dgm(landmarks), Dgm(cloud)) <= 2 e (the research notes' TDA-7 bound). The greedy choice also gives a covering radius within a factor of 2 of the best possible for the same number of landmarks (Gonzalez 1985).

Distances to each new landmark come from one GEMM against all points on the backend, so the full n x n matrix is never formed: memory is O(n + k d) beyond the points.
