Detailed Description

One block's LoReFT edit. Parameters, named as pyreft's state dict:

  • rotate_layer: R^T, (d, r) with orthonormal columns (pyreft's layout);
  • learned_source.weight: W^T, (d, r), the transpose of pyreft's (r, d), like every pulsatrix Linear weight;
  • learned_source.bias: b, (r).
    Note
    Gradient steps move R off the orthonormal set; call orthonormalize() after each optimizer step (OrthonormalizeLoReFT() does it for a model). pyreft keeps R orthonormal with torch's orthogonal parametrization instead, so training paths differ, but the edit, its gradient with respect to R and its relevance are the same for the same R.
