Detailed Description

A native C++ visualization layer (Dear ImGui + ImPlot), opt-in via the PULSATRIX_ENABLE_VIZ CMake option. Split into a pure data-transform layer (plot_data.hpp/colormap.hpp – always built as part of the core library, unit-tested) and chart widgets/dashboards that call into ImGui/ImPlot directly (built only when PULSATRIX_ENABLE_VIZ=ON, verified via the demo apps under examples/viz/ rather than GoogleTest, since a live GPU/window context isn't meaningfully testable headlessly).
