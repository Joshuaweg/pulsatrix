Visualization

Visualization in two layers. Always built in the core library and unit-tested: versioned JSON documents (json.hpp, viz/document.hpp: pulsatrix.<kind>.v1 for attributions, heatmaps, token relevance, circuit graphs, training logs and feature dashboards), dependency-free SVG figures (viz/svg.hpp, also the pulsatrix_svg tool), and the data transforms (plot_data.hpp/colormap.hpp). Opt-in via PULSATRIX_ENABLE_VIZ: live Dear ImGui + ImPlot widgets and dashboards that read the same data, checked through the demo apps under examples/viz/ rather than GoogleTest, since a live window context isn't testable headlessly. Detailed Description

Visualization in two layers. Always built in the core library and unit-tested: versioned JSON documents (json.hpp, viz/document.hpp: pulsatrix.<kind>.v1 for attributions, heatmaps, token relevance, circuit graphs, training logs and feature dashboards), dependency-free SVG figures (viz/svg.hpp, also the pulsatrix_svg tool), and the data transforms (plot_data.hpp/colormap.hpp). Opt-in via PULSATRIX_ENABLE_VIZ: live Dear ImGui + ImPlot widgets and dashboards that read the same data, checked through the demo apps under examples/viz/ rather than GoogleTest, since a live window context isn't testable headlessly.
