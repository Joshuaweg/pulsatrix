Detailed Description

Plans explanations from the explainer catalog.

The ranking, best first, compares each of these in turn and keeps catalog order on a tie:

  1. explainers whose main question it is, before those that answer it second;
  2. the reason's preference:
    • Justify: complete explainers first, then those that return an Attribution the faithfulness checks can test, then other local explainers;
    • Control and Improve: global explainers first, which look across the data;
    • Discover: global explainers first, then those that read the model's internals;
  3. explainers made for the model's kind of input before general ones;
  4. more model access before less, since an explainer that reads the computation can be checked against it.

The checks follow the reason (the roadmap's XAI table):

  • Justify requires faithfulness (DeletionCurve / InsertionCurve) and stability, and conservation for complete explainers;
  • Control requires the model-parameter randomization test and robustness (KS-4: the explanation shouldn't change much when the input barely does) for attributions, the null-model baseline for the rest, and per-slice error (KS-3), which needs labels;
  • Improve requires aggregating the explanations over a dataset;
  • Discover requires the null-model baseline and each explainer's own controls (control tasks for probes, a significance test for persistent homology, split halves for PCA). The same checks are recommended, not required, under the other reasons.
