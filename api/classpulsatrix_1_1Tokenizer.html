Detailed Description

Splits text into lowercase word/punctuation tokens – pulsatrix's first text primitive (campaign_exai_dl_library_data_pipeline, Phase 3, Decision Point 6: a minimal whitespace/punctuation tokenizer, not BPE – training a real subword-merge algorithm is a project-sized undertaking on its own).

Note
ASCII-oriented (uses std::tolower/std::isalnum/std::isspace per byte) – Unicode normalization is out of scope for this phase.
