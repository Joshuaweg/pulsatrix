Detailed Description

An atom is a predicate name applied to a tuple of Terms, e.g. edge(a, b) or ancestor(X, Y) – never a nested/compound structure, since Term itself cannot nest (see datalog_term.hpp).

Note
An atom is "ground" (a fact, suitable for a FactDatabase) iff every one of its terms is a constant. An atom with any variable term is only valid inside a rule's head or body, never inside a FactDatabase.
