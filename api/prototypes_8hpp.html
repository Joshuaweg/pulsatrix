Detailed Description

Explaining by example (XAI-4): the background inputs nearest one input that the model treats the same way and differently, and ProtoDash's weighted prototypes that summarize a dataset (Gurumoorthy, Dhurandhar, Cecchi and Aggarwal, ICDM 2019).

"This input is classed like these, and unlike those" is often easier to check than a heatmap. The nearest same-class examples are the input's prototypes; the nearest examples of another class are its contrasts, the closest cases where the model decided differently.

Distances are Euclidean, either in the input space with a per-feature scale (pass MedianAbsoluteDeviation() for tabular data in mixed units) or in a representation the caller computes, such as a layer's activations.
