Detailed Description

The series document (VIZ-9): measured points with optional intervals, for sweeps and trade-off curves, and its SVG view. The Vega-Lite view is in html.hpp.

A series is one line of (x, y) points, each with an optional interval [lo, hi] (a confidence interval, a range over seeds). A panel holds several series on shared axes, and a document holds one or more panels with the same axis labels and scales: small multiples. Either axis can be linear or logarithmic.

It follows the rules of every viz document (document.hpp): a "schema" of pulsatrix.series.v1, non-finite numbers as null plus a "nonfinite" entry, and readers that name the JSON Pointer of the first problem.
