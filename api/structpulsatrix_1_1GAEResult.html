Detailed Description

ComputeGAE()'s two outputs: the advantage estimate per step and the critic's regression target per step.

Note
Plain data, no behavior – the same small named return-struct precedent as ReparamGrad (reparameterize.hpp), StepResult (environment.hpp) and RolloutBatch (rollout_buffer.hpp). A std::pair<Tensor, Tensor> would make every call site read .first/.second for two tensors that are emphatically not interchangeable.
Both are (N, 1), row t of each belonging to stored step t – the same leading dimension as the rewards/dones/values passed in.
