Detailed Description

A representational dissimilarity matrix: the distance between every pair of n inputs.

Note
Stored condensed, as scipy's pdist stores it: pairs (0, 1), (0, 2), ..., (0, n-1), (1, 2), ..., n (n - 1) / 2 values.
