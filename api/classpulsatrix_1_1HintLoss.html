Detailed Description

FitNets' hint loss: mean((r(student) − teacher)²), with r a learned linear map from the student's feature width to the teacher's.

Note
Features are (..., width): every row along the last dimension is one feature vector, and the leading shapes must match.
The regressor is a LinearModule with a bias, started the way PyTorch starts nn.Linear (weights and bias uniform in ±1/√student_width) from seed: LinearModule itself starts at zero, which would pass no gradient back to the student. Step it with the student's optimizer, or its own: backward() accumulates its gradients.
