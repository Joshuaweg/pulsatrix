Detailed Description

How sure a model is of each prediction (KS-3): Monte Carlo dropout (Gal and Ghahramani, ICML 2016), deep ensembles (Lakshminarayanan, Pritzel and Blundell, NeurIPS 2017), and the split of a prediction's uncertainty into the part more data would remove and the part it wouldn't.

One deterministic network gives one probability per class, and nothing says how much to trust it. Several predictions of the same input that disagree do. Monte Carlo dropout gets them from one network by keeping dropout on at inference; a deep ensemble from several networks trained from different seeds. Either way the result is a set of samples of the predictive distribution, and DecomposeUncertainty() splits its entropy:

  • total, the entropy of the mean prediction, H[E p];
  • aleatoric, the mean entropy of the samples, E H[p]: what each one is unsure of, noise in the data that more data wouldn't remove;
  • epistemic, the difference, the mutual information between the prediction and the model (BALD; Houlsby et al., 2011): how much the samples disagree, which more data would reduce.

For regression, each member predicts a mean and a variance, trained with GaussianNLLLoss, and CombineGaussians() mixes them the same way.

The decomposition is only as good as the samples. Dropout samples come from one network and tend to agree more than an ensemble's; neither is the true posterior.
