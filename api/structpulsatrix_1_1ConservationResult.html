Detailed Description

The result of comparing a relevance-propagation step's input and output totals.

Note
LRP's defining property is that relevance is conserved layer-to-layer – the sum of relevance at any layer should equal the sum at the next (up to the small absorption epsilon-rule variants introduce). Before this type existed, that check lived only as test-only local lambdas in lrp_conservation_test.cpp/stability_test.cpp; this promotes it to a real, reusable API so non-test code (the ExplanationScoreCard's "trustworthiness" tile) can compute the same number without duplicating the math.
