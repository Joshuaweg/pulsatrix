Detailed Description

One attention layer's keys and values for the positions processed so far, in buffers allocated once for max_length positions, so generation never reallocates or copies the past.

Keys are stored after QK-Norm and RoPE, at the K/V head count (not repeated for grouped-query attention). MultiHeadAttentionModule::forward_cached writes new positions and advances length(); everything before length() is attended to.
