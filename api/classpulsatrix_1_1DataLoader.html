Detailed Description

Orchestrates sampling and collation into batches – pulsatrix's DataLoader (PyTorch DataLoader / torch::data::DataLoader analogue).

Note
Phase 1 ships a fully synchronous implementation (num_workers=0 is the only exercised path): DataThreadPool/BoundedQueue exist (see those headers) but are not yet wired into this class's fetch/collate path – wiring num_workers > 0 through a real staged pipeline is a dedicated, separately-tested later mission (Decision Point 7 in campaign_exai_dl_library_data_pipeline).
