Detailed Description

pulsatrix.partial_dependence.v1: a partial dependence curve over one feature, with the individual (ICE) curves it averages when they were computed (CFS-1).

Note
Holds the raw curves only. Centered and derivative ICE are views of them, computed by whoever draws them (IceResult::centered, IceResult::derivative), so every renderer agrees.
