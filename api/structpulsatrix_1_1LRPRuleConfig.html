Detailed Description

Configuration for LRP relevance propagation: which rule a module applies and its hyperparameters. A module that does not implement the requested rule throws (see Module::supports_lrp_rule()) – the rule is never silently substituted.

Note
epsilon stays the first member so aggregate initialization LRPRuleConfig{0.01f} keeps meaning "epsilon rule, epsilon 0.01". It is also the denominator stabilizer of Gamma / AlphaBeta / ZBox (Zennit's stabilizer, default 1e-6 there as well).
