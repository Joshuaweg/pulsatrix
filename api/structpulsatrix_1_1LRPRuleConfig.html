Detailed Description

Configuration for LRP relevance propagation. Selects which rule variant to apply (currently: epsilon rule only); it never changes whether a module supports LRP – that's guaranteed at compile time by Module::propagate_relevance being pure-virtual. Gamma/alpha-beta fields are added when a module first needs them, not speculatively now.
