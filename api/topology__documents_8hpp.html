Detailed Description

The persistence diagram document (TDA-9): the features of each homology dimension, with the certified error bound and any significance results, for the persistence diagram, barcode and Betti curve views in topology_views.hpp.

It follows the rules of every viz document (document.hpp): a "schema" of pulsatrix.persistence_diagram.v1, non-finite numbers (an essential feature's infinite death, an untested feature's NaN p-value) as null plus a "nonfinite" entry, and readers that name the JSON Pointer of the first problem.
