◆ ablation_effect

float pulsatrix::CircuitNode::ablation_effect

Ablation importance: the L2 distance between the network's real output and the output it produces when this node's activation is replaced by zeros.

Note
Larger means "zeroing this node changes what the network outputs more", i.e. this node matters more. Always >= 0. The output node's score is 0.0f by convention, not by computation – see ExplainerContext::build_circuit_graph().
