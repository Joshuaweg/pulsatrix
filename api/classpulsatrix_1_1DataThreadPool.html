Detailed Description

Minimal, generic thread pool for CPU-side data pipeline work (fetch, decode, transform, collate stages) – campaign_exai_dl_library_data_pipeline's staged- pipeline backbone alongside BoundedQueue. Deliberately not tied to Dataset/DataLoader types.

Note
This is pulsatrix's first concurrent code path. No production DataLoader path exercises this class yet in Phase 1 – see bounded_queue.hpp's matching note.
