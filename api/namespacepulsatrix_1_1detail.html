int64_t  coalition_size 
)
inline

The SHAP kernel pi(z') = (n-1) / [C(n,|z'|) * |z'| * (n-|z'|)], for 1 <= |z'| <= n-1.

Note
Undefined (division by zero) at |z'|=0 and |z'|=n – those coalitions are handled separately (they anchor f(baseline) and f(x) exactly), never passed here.

Solves A*x = b via Gaussian elimination with partial pivoting.

Exceptions
std::runtime_errorif a pivot is too close to zero (a near-singular system) – a legitimate, caller-triggerable condition (e.g. degenerate perturbation sampling), not a programmer error, per this codebase's assert-vs-throw convention.
Note
A, b are taken by value – elimination is done in place on the local copies.
