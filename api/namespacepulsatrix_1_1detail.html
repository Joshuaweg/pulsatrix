◆ ShapKernelWeight()

float pulsatrix::detail::ShapKernelWeight ( int64_t  n,
int64_t  coalition_size 
)
inline

The SHAP kernel pi(z') = (n-1) / [C(n,|z'|) * |z'| * (n-|z'|)], for 1 <= |z'| <= n-1.

Note
Undefined (division by zero) at |z'|=0 and |z'|=n – those coalitions are handled separately (they anchor f(baseline) and f(x) exactly), never passed here.
