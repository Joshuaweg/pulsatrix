Detailed Description

loss = -log(softmax(logits)[target_class]), combined for numerical stability (subtract the max logit before exponentiating) rather than computing softmax and log separately.

Note
Not a Module subclass, same as MSELoss – losses are the seed point relevance/ gradient propagation starts from, not something propagate_relevance is defined for.
Takes an integer class index, not a one-hot Tensor – the standard classification- loss convention (mirrors torch.nn.CrossEntropyLoss's (logits, target) signature), and avoids inventing a one-hot Tensor construction step every caller would otherwise need.
