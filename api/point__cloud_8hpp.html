Detailed Description

The input to topological data analysis: a layer's activations as a set of points, one row per input or per position, gathered across batches.

Persistent homology measures the shape of a finite set of points. A layer's activations come as batches of tensors, (batch, ...), from ActivationSnapshot or a model's hooks. PointCloud turns those batches into one (n, dimension) set of points, and records where each point came from, so a loop or a cluster found later can be traced back to the inputs and positions that form it.

How a sample becomes points is the one choice to make (PointPooling):

  • Flatten (the default): one point per sample, every dimension after the batch flattened. Right for an MLP layer or a classifier's logits.
  • PerPosition: one point per token or pixel, with the feature axis as its coordinates. Right for the geometry of token representations.
  • Mean, Max or Last: one point per sample, pooled over its positions. Last is a causal language model's summary of the whole input.
