Detailed Description

Principal component analysis of a layer's representations (INT-5): 2D and 3D views, directions to steer along, and fewer dimensions for what comes after.

FitPca() finds the directions along which a set of inputs' representations vary most. PcaProject() places inputs on them, for a scatter plot (viz/projection.hpp) or as input to methods that want fewer dimensions. PcaComponent() gives a direction as a steering vector.

It matches scikit-learn's PCA (the full solver): the data are centered, variances divide by n - 1, and each component's sign makes its largest-magnitude entry positive, so the same data always give the same picture. Everything is in double precision on the host, through the covariance (width x width) or the Gram matrix (n x n), whichever is smaller.

Two cautions. Components whose variances are close can swap or rotate between two samples of the same data, so a 2D picture isn't always stable: PcaSplitHalfOverlap() checks. And the largest directions of variance aren't necessarily the ones the model uses: a direction found here is a hypothesis to test, for example by steering along it.
