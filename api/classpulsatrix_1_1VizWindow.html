Detailed Description

Owns a GLFW window, OpenGL3 context, and ImGui/ImPlot context for the lifetime of one demo app. Every examples/viz/*_demo.cpp uses this instead of hand-rolling the standard imgui_impl_glfw_opengl3 boilerplate.

Note
This class – and everything that calls into ImGui or ImPlot – is deliberately NOT unit-tested via GoogleTest (see plans/okay-we-have-now-buzzing-moth.md Testing Strategy): a live window/GL context isn't meaningfully testable headlessly on this project's dev/CI machines. Verification is via manually running the demo apps.
