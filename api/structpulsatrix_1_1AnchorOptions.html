◆ epsilon_stop

double pulsatrix::AnchorOptions::epsilon_stop = 0.0

An anchor is accepted when its precision is at least the threshold and its lower bound above threshold - epsilon_stop.

Note
The reference implementation uses 0.05, which accepts anchors whose true precision is below the threshold: on a model where one predicate has true precision 0.925, 22 of 50 seeds returned an anchor below 0.95 (that predicate plus an irrelevant one, lifted over the threshold by sampling noise). With 0, none did, for about 2.5 times the model calls.
