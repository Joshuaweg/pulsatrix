Detailed Description

A global surrogate: a shallow decision tree fitted to a model's predictions, with its fidelity to the model on held-out inputs (XAI-4; TREPAN, Craven and Shavlik 1996).

A surrogate answers "how does the model work overall?" with rules a person can read, and its fidelity says how far to trust them: a tree that agrees with the model on 70% of new inputs describes a different model 30% of the time. Below about 85% at a readable depth, the tree isn't a description of the model (the falsifier in the roadmap's research notes).

The tree is CART as scikit-learn builds it (DecisionTreeClassifier and DecisionTreeRegressor with splitter="best"): Gini or squared-error impurity, thresholds halfway between consecutive distinct values, x <= threshold going left, nodes numbered depth first. Ties between features go to the lower index, where scikit-learn breaks them at random.

SurrogateTreeOptions options;
options.max_depth = 3;
SurrogateTreeResult s = FitSurrogateTree(predict, background, options);
std::cout << DescribeSurrogateTree(s.tree, feature_names);
// s.fidelity.test: the share of held-out inputs where the tree's class is the model's
