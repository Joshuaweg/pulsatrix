Detailed Description

Viz documents for proteins (PLM-5): the mutation map, the sequence logo, the contact map and residue tracks, with builders from a protein language model's outputs.

They follow the rules of every viz document (document.hpp): a "schema" of pulsatrix.<kind>.v1, non-finite numbers as null plus a "nonfinite" entry, and readers that name the JSON Pointer of the first problem. Positions are residues of one sequence, numbered from first_position (1 unless the sequence is a fragment), as variant tables number them.
