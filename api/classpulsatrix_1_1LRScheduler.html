Detailed Description

template<typename Optimizer>
class pulsatrix::LRScheduler< Optimizer >

Applies an LRSchedule to an optimizer (SGDOptimizer, AdamOptimizer, AdamWOptimizer): each rate becomes its base rate times the schedule's multiplier, like PyTorch's LambdaLR.

Note
The base rates are the optimizer's learning rate and each parameter group's (TRN-1) when the scheduler is built, so set up the groups first. Building the scheduler applies step 0 (with warmup, a rate of 0). Call step() once after each optimizer step.
