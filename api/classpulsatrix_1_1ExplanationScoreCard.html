Detailed Description

Aggregates, per prediction, a 2x2 panel: top row is "what was shown, how confident was the model" (input label + ConfidenceMeter), bottom row is "how trustworthy is this explanation" (LRP conservation delta + explainer stability), visually separated by a rule (Gestalt proximity grouping – these are two different semantic questions, not one undifferentiated block of numbers).
