Detailed Description

What did a fine-tune change? The fine-tuned model's relevance minus the base model's for the same prediction, input by input and token by token across a dataset, and intruder dimensions: new top singular directions in the fine-tuned weights (TRN-11).

Works for a fine-tune held as adapters on the base model (LoRA, IA³, LoReFT), which DiffAdapterRelevance() switches off and on, and for two separate models of the same architecture, such as a full fine-tune and its base, with DiffRelevance().
