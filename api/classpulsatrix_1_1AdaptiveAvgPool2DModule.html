Detailed Description

Pools a rank-4 (N, C, H, W) input to (N, C, out_h, out_w), as AdaptiveAvgPool2d((out_h, out_w)): ResNet's global pooling is (1, 1), VGG's is (7, 7).

Note
Only sizes that divide evenly are supported (H divisible by out_h, W by out_w): the windows are then the non-overlapping (H / out_h, W / out_w) of AvgPool2DModule, with its backward and its LRP z-rule. PyTorch's uneven windows (overlapping, of different sizes) are refused rather than approximated.
