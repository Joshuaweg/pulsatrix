Detailed Description

A rule: a head atom entailed whenever every body atom is simultaneously satisfiable under one consistent variable substitution.

Note
Enforces Datalog "range restriction"/safety at construction: every variable that appears in the head must also appear in at least one body atom. Without this, a rule like p(X) :- q(a). would be free to bind X to an unbounded/arbitrary constant, breaking the decidable-fragment termination guarantee this whole phase depends on (campaign doc Decision Point 1: "Datalog's decidable fragment always terminates via bottom-up fixpoint"). A rule with an empty body is never safe unless its head is also empty-arity (there is no such head shape here), so an empty body with a non-empty head always throws.
