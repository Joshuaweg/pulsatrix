Detailed Description

Holds a credential, such as an LLM provider's API key.

Note
There is no operator<< and no conversion to std::string, so a Secret can't end up in a log line or an error message by accident: the only way to read it is reveal(), which is easy to search for. redacted() describes it without its contents. The memory holding the value is overwritten when the Secret is destroyed or assigned over.
