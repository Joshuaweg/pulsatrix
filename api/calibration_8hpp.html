Detailed Description

Calibrating a model's probabilities (KS-13): temperature scaling fitted on held-out data, and the error in log-odds against reference probabilities, by probability band.

Temperature scaling (Guo, Pleiss, Sun and Weinberger, ICML 2017) divides a model's logits by one number T, fitted to minimize the log loss on held-out labeled data. It changes how confident the model is, never which class it ranks first. The log loss is convex in 1/T, so the fit is a safeguarded Newton iteration and finds the global minimum.

Log-odds error measures probabilities against reference probabilities rather than labels: |logit(p) - logit(q)|. It is meant for rare events. The expected calibration error (performance.hpp) averages over bins and is dominated by common cases, so a model that says 1e-2 where the truth is 1e-4 barely moves it; in log-odds that is an error of 4.6. LogOddsError() reports the error separately in each band of the reference probability, with optional importance weights for test sets that oversample rare cases.
