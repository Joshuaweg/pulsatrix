◆ RunToolLoop()

ToolLoopResult pulsatrix::orch::RunToolLoop ( Provider &  provider,
ChatRequest  request,
const ToolExecutor &  execute,
const ToolLoopOptions &  options = {} 
)

Sends request, runs each tool the model calls with execute, and sends the results back, until the model stops calling tools or options.max_turns requests have been made.

Note
The results of one answer's calls go back together, first in the next user message and in the order of the calls, as the Anthropic API requires. A PauseTurn answer is sent back as it is, to let the model continue.
Exceptions
ProviderErroror HttpError as Provider::chat() does.

◆ StrictModeProblem()

std::string pulsatrix::orch::StrictModeProblem ( const JsonValue &  schema)

Why schema can't be used with Anthropic's strict tool use, or "" if it can.

Note
Strict mode needs "additionalProperties": false on every object, and doesn't support numeric, string-length or most array constraints, oneOf, not, or enum values that are arrays or objects. Its limits across a whole request (20 strict tools, 24 optional parameters, 16 union-typed parameters) aren't checked here.
Exceptions
std::invalid_argumentif schema doesn't pass CheckSchema().
