Detailed Description

IA³ (Liu et al., 2022): fine-tune a frozen model by learning one rescaling vector per adapted Linear layer, on its output (keys, values) or its input (the MLP's down projection), and save and load it as a PEFT adapter.

An IA³ layer computes y = (x W + b) ⊙ l, or, for a feedforward layer, y = (x ⊙ l) W + b. Each vector starts at 1, so the adapted model starts as the base model, and it has one value per channel: about 58 thousand values for SmolLM2-135M on the default layers. Either form is the base layer with rescaled weights, W diag(l) or diag(l) W, so the fine-tune can be read off directly (which channels it amplified, which it switched off), and LRP runs on the rescaled layer exactly.
