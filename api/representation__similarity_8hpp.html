Detailed Description

How similar two layers' representations of the same inputs are: linear CKA, RSA and SVCCA.

Centered kernel alignment (Kornblith et al., ICML 2019) compares two representations of the same n inputs, for example one layer of two models, two layers of one model, a model before and after fine-tuning, or the same layer computed on two backends. It is 1 when one representation is a rotation and uniform scaling of the other, and near 0 when they are unrelated. Unlike comparing activations directly, it doesn't need the layers to have the same width or their neurons to line up.

The debiased estimator (Song et al., JMLR 2012; Nguyen et al., ICLR 2021) is the default. The original, biased one is pulled towards 1 when there are few inputs for the width: two random, unrelated representations of 50 inputs with 1,000 features each score 0.95 with it and about 0 debiased.

Two older measures are here too, for comparison with published results that use them:

  • RSA (representational similarity analysis; Kriegeskorte et al., Frontiers in Systems Neuroscience 2008) describes each representation by how far apart it puts every pair of inputs, its representational dissimilarity matrix (RDM), and correlates the two RDMs. It compares a model with anything that orders the same inputs, a brain recording or a hand-made model of the categories, and RsaPermutationTest() says whether the agreement could be chance.
  • SVCCA (Raghu et al., NeurIPS 2017) keeps each representation's top singular directions (99% of the variance by default) and finds the pairs of directions, one in each, that correlate most. It is invariant to any invertible linear map, which CKA isn't. That makes it blind to how a layer weights its directions, and Kornblith et al. found it worse than CKA at matching corresponding layers. It is also biased upwards: canonical correlations are fitted to the inputs, so unrelated representations score well above 0 unless there are many more inputs than kept directions.
