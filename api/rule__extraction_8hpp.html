Detailed Description

Rules from trees, run by the Datalog engine (roadmap KD-3): a surrogate or distilled tree becomes a Datalog program that classifies the same way.

Every root-to-leaf path of a tree is one rule. A crisp tree (FitDecisionTree's, or FitSurrogateTree's, distilled from a model) gives

predict(S, versicolor) :- sample(S), gt(S, petal_length, 2.45), le(S, petal_width, 1.75).

with the conditions on one feature merged to the tightest (two le on a feature keep the smaller threshold), and facts le(s, f, t) or gt(s, f, t) for each sample and each threshold the rules use. The Datalog engine's fixpoint then holds predict(s, c) for exactly the class the tree predicts.

A SoftDecisionTree gives one rule per leaf over weighted facts: right(s, n) with the probability of going right at node n, left(s, n) with its complement, and leaf(l, c) with leaf l's probability of class c:

predict(S, C) :- left(S, n0), right(S, n1), leaf(l1, C).

Evaluated over the real semiring, which sums over derivations the product of their facts' weights, predict(s, c) is Σ_ℓ P_ℓ(s) Q_ℓc: exactly the tree's class probability.

Datalog constants are strings, so thresholds are written with 9 significant digits, enough to tell any two floats apart; the facts are written the same way, so rules and facts match.
