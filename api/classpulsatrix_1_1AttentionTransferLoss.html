Detailed Description

Attention transfer: mean over examples and positions of (q_s − q_t)², where q is the L2-normalized map mean_c |A_c|^p of each example's features.

Note
Features are (N, C, ...): the dimensions after the channels are flattened into positions. Computed on the host in double precision, whatever the tensors' device; the gradient is returned on the student features' device.
p = 2, the default and the paper's choice, is the authors' x.pow(2).mean(1); other p use |A|^p, the paper's definition.
