Detailed Description

How well a model does (KS-3): a classifier's accuracy, log loss, Brier score, calibration and per-class scores; a regressor's errors; and the error on each slice of the data, with a test of whether a slice is worse than the rest.

These answer the Performance question of the XAI question bank. Every number here matches scikit-learn's (or, for the tests, SciPy's) on the same data; tests/performance_test.cpp checks them against values from tools/generate_performance_reference_values.py.

Calibration is the expected calibration error of Guo, Pleiss, Sun and Weinberger (ICML 2017): group the predictions into equal-width bins of confidence, the largest probability, and average the gap between each bin's accuracy and its mean confidence, weighted by its size. A model whose 0.8-confidence predictions are right 80% of the time is calibrated.

A model can do well on average and fail one group. PerSliceError() reports the error on each slice and tests each against the rest of the data, so a failure confined to one slice isn't averaged away. It is the per-slice error check the Control reason requires.
