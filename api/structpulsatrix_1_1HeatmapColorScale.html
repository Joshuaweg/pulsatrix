◆ is_signed

bool pulsatrix::HeatmapColorScale::is_signed

True iff the grid has any negative value: the caller must then use a diverging colormap (DivergingColormap) centred on zero, since scale_min == -scale_max. When false, values are unsigned magnitudes and a sequential colormap (Viridis) over [0, scale_max] is correct.
