Detailed Description

Linear probes with controls (INT-3): a multi-class probe trainer, Hewitt and Liang's control task and selectivity, and a comparison against a baseline representation.

A probe's accuracy alone doesn't say the representation encodes a concept: the probe may have learned the task itself, for example by memorizing a label for each word. Hewitt and Liang ("Designing and Interpreting Probes with Control Tasks", EMNLP 2019) give each token type a random but fixed label and train the same probe on that. A control task can only be learned by memorizing types, so selectivity, the task accuracy minus the control accuracy, is what the representation adds beyond that.

When there are few types the control task is no control: a linear probe learns 20 amino acids' labels from any representation that encodes identity. Compare against a baseline representation instead, such as one-hot local sequence (SequenceWindowFeatures()) or the same layer of a randomly initialized model.
