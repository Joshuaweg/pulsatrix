Detailed Description

Distillation loss between a student's and a teacher's logits, (..., classes): every row along the last dimension is one distribution.

Note
Device-generic: everything runs on the logits' device through softmax_rows, logsumexp_rows and axpby. forward() reads back the loss's parts; with targets it also reads the targets, one float per row, to find the rows to keep.
The teacher's logits get no gradient: the teacher is fixed.
