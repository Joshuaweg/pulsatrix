Detailed Description

sum over tokens of -log softmax(logits)[target], divided by a normalizer; tokens whose target is the ignore index (padding) contribute nothing.

Note
Logits are (..., classes): every row along the last dimension is one token. Targets have the leading shape (...), as whole-number floats (the library's index convention).
Gradient accumulation: averaging each micro-batch's own mean is wrong when micro-batches hold different numbers of real tokens (the bug Hugging Face Trainer fixed in v4.46). Count the tokens of the whole accumulation window with CountTargetTokens() and pass that total as every micro-batch's normalizer; the accumulated gradients then equal one big batch's.
Device-generic: the per-row softmax and gradient run through DeviceBackend::rl_rows, the same row kernels as PolicyGradientLoss with a weight of 1 per real token and 0 per ignored one.
