Detailed Description

The split Tokenizer::Tokenize makes: runs of ASCII letters, digits and apostrophes are words, ASCII whitespace separates, and every other character is a token of its own.

Note
Tokenizer::Tokenize works byte by byte and splits a non-ASCII character into its bytes; this keeps the character whole. On ASCII text the two agree.
