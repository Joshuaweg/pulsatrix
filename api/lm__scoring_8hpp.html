Detailed Description

Prompt/completion data for a causal language model (LLM-10): read it from JSONL, batch it with the prompt masked out of the loss, and score it, as log P(completion | prompt) or as the probabilities of a few single-token choices ("P(True)").

Fine-tuning a model to answer a question trains only the answer: CollatePromptCompletions() sets every target outside the completion to TokenCrossEntropyLoss::kIgnoreIndex, so the loss is the completion's log loss and nothing else. Scoring reads the same positions back.

Batches are right-padded. Causal attention never lets a real token attend to the padding after it, so padding changes no real position's logits (tests/lm_scoring_test.cpp checks a padded batch against each example alone).

The scorers copy only the logit rows they need to the host, gathered on the device: a batch's full logits are (N, L, vocab), about 400 MB for SmolLM2 at N = 8, L = 256.
