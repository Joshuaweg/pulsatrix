Detailed Description

Parses a text/event-stream body fed in chunks of any size, as the WHATWG HTML specification defines it.

Note
Lines may end in CRLF, LF or CR, also split across chunks. A leading byte-order mark, comment lines (:) and unknown fields are ignored. An event with no data isn't dispatched. Every event type is passed on: a provider dispatches on SseEvent::type and ignores the types it doesn't know, which APIs add without notice (ping, for one).
