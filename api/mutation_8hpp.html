Detailed Description

Genetic-algorithm mutation operators: bit-flip (generic boolean genotypes) and Gaussian, polynomial (real-valued genotypes).

Note
Same pure-core/RNG-wrapper split as selection.hpp and crossover.hpp: every stochastic operator's pure core takes an explicit mask/noise/draw, making its correctness hand-derivable independent of any particular RNG's output stream.
