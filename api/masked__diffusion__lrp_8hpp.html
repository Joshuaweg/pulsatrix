Detailed Description

Explaining a masked diffusion LM's generation (DIFF-3): commitment-graph LRP, which explains tokens written at any step back to the prompt by chaining AttnLRP through the tokens committed in between, and the checks that test it by replaying the trajectory.

In a carry-over sampler (MDLM's, LLaDA's) no hidden state passes from one step to the next: each step is one forward pass over the current sequence, and the committed tokens are the only channel between steps. So relevance that one step's pass puts on a token committed earlier is re-seeded at the step that wrote it, onto the logit that produced it, and the steps are walked in reverse. With the forward activations fixed every rule in use is linear in the incoming relevance, so each step needs one relevance pass however many tokens it seeds. See docs/interpretability/diffusion-lrp.md (D2) for the derivation and its limits.
