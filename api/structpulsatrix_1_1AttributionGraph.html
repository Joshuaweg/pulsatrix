Detailed Description

An attribution graph as Neuronpedia's schema (graph-schema.json) and circuit-tracer's create_graph_files describe it.

Note
The viewer places a node by its layer ("E" for embeddings, then "0", "1", ..., and the logit layer last) and its ctx_idx (token position), and draws a link's weight as its width and sign.
