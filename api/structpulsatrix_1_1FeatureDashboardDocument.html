Detailed Description

pulsatrix.feature_dashboard.v1: one learned feature (for example a sparse autoencoder unit) with its activation statistics and top-activating examples.

Note
Follows the core of SAEDashboard and Neuronpedia's feature pages. Logit effects and other fields can be added later within v1.
