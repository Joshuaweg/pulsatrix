Detailed Description

Anchors (Ribeiro, Singh and Guestrin, "Anchors: High-Precision Model-Agnostic Explanations", AAAI 2018): an if-then rule around one input that keeps the model's prediction with high probability, whatever the other features do (XAI-4).

An anchor answers "how to still be this": which conditions, if they hold, keep the prediction. IF income > 0.71 AND debt <= -0.12 THEN class 1, with

  • precision: the share of inputs satisfying the rule that the model gives class 1, estimated by sampling, with a confidence bound;
  • coverage: the share of the background data the rule applies to.

The predicates are the reference implementation's for ordinal features: each feature is cut at the background's percentiles (quartiles by default), and every half-line at a cut that contains the input is a predicate, x > e for cuts below the input and x <= e for cuts above it. An anchor may hold two on one feature, which make an interval. An input satisfying the anchor is drawn by taking a random background row and, for each anchored feature, a background value inside its interval; features are drawn independently of one another, as the reference implementation does when too few rows satisfy every predicate at once.

The search is the paper's: a beam search that adds one predicate at a time, using KL-LUCB to find the most precise candidates with few model calls, and keeps, among the anchors whose precision clears the threshold, the one with the highest coverage.

Note
Precision is estimated, not guaranteed (Anchor::precision_lower is the bound), and an anchor can cover a sliver of the data: read both.
