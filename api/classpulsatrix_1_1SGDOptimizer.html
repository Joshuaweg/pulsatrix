Parameters
moduleModule to update. Safe no-op if it has no parameters.
Note
Not yet backend-generic – dereferences Tensor::data() directly in a raw host loop. PULSATRIX_ASSERT(device() == DeviceType::Cpu) on each parameter guards against silent UB on a CUDA-backed Tensor; see campaign_exai_dl_library_phase1_5_cuda_backend.md's scope decision. Do not remove this guard without actually retrofitting the method to route through DeviceBackend.
