std::vector<std::string> pulsatrix::LoRAConfig::target_modules

The layers ApplyLora() adapts, PEFT style: a layer matches a name if its own name is that name or ends with "." and that name (q_proj matches layers.0.mha.q_proj). Empty means every LinearModule but an output head named lm_head, as PEFT's "all-linear". (PEFT's own default for Llama is q_proj and v_proj only.)
