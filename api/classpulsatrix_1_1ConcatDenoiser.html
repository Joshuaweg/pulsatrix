Detailed Description

A Module that reads [x_t, embedding(t), c] as one row, conditioned by concatenation as in tests/diffusion_integration_test.cpp: x_t, then a sinusoidal timestep embedding (SinusoidalTimestepEmbedding), then a fixed conditioning vector such as a one-hot class. Its input relevance is split back into those three parts.
