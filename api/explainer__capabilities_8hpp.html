Detailed Description

What each explainer answers: the nine question categories (Liao, Gruen and Miller, CHI 2020), the four reasons to explain (Adadi and Berrada, 2018), and a machine-readable declaration of every explainer's question, scope, model access and inputs (XAI-1).

Pulsatrix's explainers are separate classes and free functions with different signatures, so the declarations live in one catalog, ExplainerCatalog(). The classes with an explain() method also return their own entry from a static capabilities().
