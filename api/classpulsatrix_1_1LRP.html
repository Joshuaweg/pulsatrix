Detailed Description

Whole-model LRP: runs the forward pass, seeds relevance at the chosen output(s), and propagates it to the input through every module's own propagate_relevance() rule.

Note
The per-layer rules are the ones each Module implements (currently the epsilon-rule family – see each module's propagate_relevance() doc); config is passed to all of them. Bias terms absorb relevance under the epsilon rule, and the AttnLRP softmax / attention rules do not conserve exactly, so sum(values) matches the seeded total only for bias-free, conservative stacks. The Attribution's metadata reports both sums.
Device-generic: the seed is assembled on the host (one device->host copy of the network output when seeding with output values) and uploaded through backend, which must be the backend the network's output lives on.
