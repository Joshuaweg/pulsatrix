Detailed Description

H0 persistence, the clusters of a point cloud across scales, from its minimum spanning tree.

In the Vietoris-Rips filtration every point is a component at scale 0, and two components merge when the shortest edge between them appears. That is single-linkage clustering, and the merge scales are the edge lengths of a minimum spanning tree (Carlsson and Memoli, JMLR 2010, show single linkage is the one stable clustering of this kind). So H0 needs no boundary matrices: Prim's algorithm on the distance matrix gives it exactly, in O(n^2) time and O(n) extra memory.

H0 only sees the tree. Research notes for this epic warn that many recent "LLM topology" results use H0 alone; check such a result against plain nearest-neighbor statistics (nearest_neighbors.hpp), which see much of the same thing.
