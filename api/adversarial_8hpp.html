Detailed Description

Adversarial attacks on a classifier (KS-4): the fast gradient sign method (Goodfellow, Shlens and Szegedy, ICLR 2015) and projected gradient descent (Madry et al., ICLR 2018), under the L∞ or L2 norm, untargeted or targeted, and the robust accuracy they leave.

An adversarial example is an input changed by less than ε, in some norm, that the model classifies differently. How small an ε suffices says how robust the model is; which inputs fall first says where it is fragile. That answers the Control reason's question, what could make this model fail, with a number.

Both attacks follow the gradient of the cross-entropy loss with respect to the input:

  • FGSM takes one step of size ε: x + ε sign(∇ₓL) under L∞, x + ε ∇ₓL / ‖∇ₓL‖₂ under L2 (the fast gradient method).
  • PGD starts at a random point of the ε-ball, takes steps steps of size α the same way, and after each one projects back onto the ball and into the input's valid range.

A targeted attack descends the loss of a chosen class instead of ascending the true one's. The steps, the projection and the random start follow torchattacks' FGSM, PGD and PGDL2; tests/adversarial_test.cpp checks them against tools/generate_adversarial_reference_values.py, a numpy implementation of the same updates.

PGD is a lower bound on what an attacker can do: a model that resists it may fall to a stronger attack. Robust accuracy measured with it is an upper bound on the true robust accuracy.
