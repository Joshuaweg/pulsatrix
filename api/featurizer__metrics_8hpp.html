Detailed Description

How good a featurizer is (FEAT-3), after SAEBench (Karvonen et al., arXiv 2503.09532): reconstruction (explained variance, cosine, norm ratio, L0, dead and dense latents), loss recovered when the reconstruction is spliced back into the model, and feature absorption (Chanin et al., arXiv 2409.14507) with a linear probe as its baseline.

Note
SAEBench's authors find that these proxies don't reliably predict how useful a featurizer is. Report them with a baseline: the same metrics for a featurizer trained on a randomly initialized model's activations (NullModelBaseline, null_model_baseline.hpp), and, for a concept, a linear probe on the raw activations, which FeatureAbsorption always fits.
