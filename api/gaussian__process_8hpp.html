Detailed Description

Gaussian-Process regression surrogate for Bayesian Optimization – the "gaussian bands" technique named at this campaign's own drafting (Snoek, Larochelle, Adams, "Practical Bayesian Optimization of Machine Learning Algorithms," NeurIPS 2012).

Note
Zero-mean prior, squared-exponential (RBF) kernel. Posterior mean/variance both reduce to solving a linear system against the training kernel matrix – resolved via SolveLinearSystem (linear_algebra.hpp), reused rather than duplicated; see that file's own header comment for this campaign's Decision Point (c) resolution (Gaussian elimination per query, not a new Cholesky utility, at this campaign's stated small-trial-count scope).
