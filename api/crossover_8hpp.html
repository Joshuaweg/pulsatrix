Detailed Description

Genetic-algorithm crossover operators: one-point, two-point, uniform (generic sequence genotypes), and blend/BLX-alpha, simulated binary (SBX) (real-valued genotypes).

Note
Every stochastic operator splits into a pure, deterministic core taking an explicit crossover point/mask/gamma/draw, plus a thin RNG-driven wrapper – the same pattern selection.hpp established, for the same reason: hand-derivable/closed-form correctness tests independent of any particular RNG's output stream.
