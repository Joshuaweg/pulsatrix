Detailed Description

AttnLRP for an ESM-2 EncoderLM: explains a target (EncoderTarget) as relevance on the input residues, with LXT's rules by default (the identity rule on LayerNorm and GELU, the uniform rule at attention's matmuls, epsilon elsewhere), so it matches LXT's AttnLRP.

Relevance at the output is the explained value itself, as LXT seeds it (value.backward()): the residues' relevance, with <cls>'s and <eos>'s, adds up to roughly that value; LRP through biases and norms isn't exactly conservative.

The explanation as an attribution graph over residues (VIZ-4's format, for Neuronpedia's and circuit-tracer's viewers): a node per layer and token, links carrying relevance between adjacent layers, and the output. The output's label is EncoderTarget::describe(), with the predicted token's probability for a masked or mutation target (1 for a head). Only config among options' rules is ignored: the explainer's own rules apply.

Note
Cost: explain(), then one layer LRP pass per layer and token.
Exceptions
std::invalid_argumentas explain(), or for a sequence longer than max_tokens - 2.
