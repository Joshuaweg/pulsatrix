size_t inexact_line_offset_differences = 0
 Lines that don't round-trip exactly whose offsets differ: counted, not failed. Such a line was changed by the normalizer (NFC) or lost characters the vocabulary lacks (dropped without an unknown token, as Hugging Face drops them). Hugging Face's offsets there are positional: a composed character gets only its first source character, characters after a canonical reordering get their neighbours' spans, and every token after a dropped character shifts left. pulsatrix tracks each byte's actual source.
