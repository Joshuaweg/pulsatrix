Detailed Description

The Gaussian negative log likelihood, for regressors that predict their own noise (Nix and Weigend, 1994; Lakshminarayanan et al., 2017): the network outputs two values per input, a mean mu and s, and its variance is softplus(s) + min_variance, which keeps it positive.

loss = mean_n 0.5 (log var_n + (y_n - mu_n)^2 / var_n), PyTorch's GaussianNLLLoss with full=False on that variance.

Note
Not a Module, like the other losses. It computes on the host and returns the gradient on the prediction's device.
