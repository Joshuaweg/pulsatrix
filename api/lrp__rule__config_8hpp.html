Detailed Description

Selects which LRP rule variant a Module::propagate_relevance() call uses.

See also
Module::propagate_relevance(), and the per-layer LRP rule implementations in Deep Learning Modules and Layers (e.g. LinearModule, Conv2DModule, TransformerBlock) – LRP rules live alongside each layer's forward/backward math, not in a separate file.
