Detailed Description

One full sampled trajectory: every state the forward policy acted from, the action taken at each, and the trajectory-level quantities Trajectory Balance (and Detailed Balance/SubTB, in later missions) need.

Note
states/actions deliberately are NOT enough on their own to recompute sum_log_pf/sum_log_pb – they exist so a training loop's second pass can re-forward() the policy network at each state (refreshing its single-most-recent-call cache) and apply the now-known per-step gradient. See mission_trajectory_balance_loss.md's Design section ("Two-pass rollout").
