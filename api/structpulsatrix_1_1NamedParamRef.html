Detailed Description

A parameter together with its hierarchical, dot-separated name relative to the module that reported it (weight, mha.q_proj.bias, 0.weight).

Note
Leaf names follow PyTorch where a PyTorch analog exists (weight/bias, including Conv2D's kernel and the norms' gamma/beta); otherwise they are the C++ member name without its trailing underscore. A container prefixes each child's names with that child's accessor name (or its index, for SequentialModule). Roadmap FND-1.
