Detailed Description

Bayesian-Optimization acquisition functions over a GP posterior: Expected Improvement, Probability of Improvement, GP-Upper-Confidence-Bound (Snoek, Larochelle, Adams, "Practical Bayesian Optimization of Machine Learning Algorithms," NeurIPS 2012).

Note
Maximization convention throughout, matching this campaign's own established convention (Evolutionary DL's selection/crossover operators, this campaign's SearchSpace-driven samplers) – a caller minimizing a loss negates it first.
